# 15分ループタイマー

作業タイマーと休憩タイマーを交互にくり返す、ポモドーロ風の Chrome 拡張です。

```
[開始] → 作業(15分) → 🔔 鳴る → [止める] → 休憩(30秒) → 🔔 鳴る → [止める] → 作業(15分) → …
                                                     [ループを終了] でいつでも完全停止
```

- アラームは止めるまで鳴り続けます。止めるとすぐ次のタイマーが始まります
- 止める方法: ポップアップの「止めて休憩へ / 止めて作業へ」、デスクトップ通知のクリック、通知の「止める」ボタン、通知を閉じる
- 「ループを終了」(ポップアップ・通知のボタン)でループを完全に止めます
- 作業時間(分)・休憩時間(秒)はポップアップで変更でき、次のタイマーから反映されます
- ブラウザを閉じるとループも終了します

## 使い方

```sh
pnpm install
pnpm build
```

1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で `.output/chrome-mv3` を選ぶ
3. ツールバーのアイコンからポップアップを開いて「開始」

開発中は `pnpm dev` で、ホットリロードが効く Chrome が立ち上がります。

## 構成

| ファイル | 役割 |
| --- | --- |
| `utils/timer.ts` | 状態遷移(純粋関数)。`idle → work → workEnded → rest → restEnded → work …` |
| `entrypoints/background.ts` | 状態に合わせてアラーム・音・通知・バッジを切り替える |
| `entrypoints/offscreen/` | アラーム音を鳴らす offscreen document(閉じると止まる) |
| `entrypoints/popup/` | 残り時間の表示と操作ボタン、設定 |

## コマンド

| コマンド | 内容 |
| --- | --- |
| `pnpm dev` | 開発サーバー |
| `pnpm build` | ビルド(`.output/chrome-mv3`) |
| `pnpm zip` | Chrome ウェブストア提出用の zip を作る |
| `pnpm test` | 単体テスト(Vitest) |
| `pnpm compile` | 型チェック |
